# CSS Subgrid: Align Nested Elements to the Parent Grid

CSS Grid is powerful, but for years it had a limitation: grid items couldn't align their children to the **parent grid's tracks**. Each grid item would define its own internal grid, making cross-card alignment impossible without JavaScript. **Subgrid** solves this.

## The Problem Subgrid Solves

Imagine three product cards in a grid. Each card has a title, description, and button. The titles are different lengths, making the descriptions start at different positions — misaligned across cards.

```css
/* Without subgrid — each card defines its own layout */
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1.5rem;
}

.card {
    display: flex;
    flex-direction: column; /* Can't align across cards */
}
```

No matter what you do with flexbox inside the card, the descriptions won't align across cards because each card is independent.

## Subgrid to the Rescue

With subgrid, each card **participates in the parent grid's row tracks**:

```css
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: auto; /* Tracks defined here */
    gap: 1.5rem;
}

.card {
    display: grid;
    grid-row: span 3; /* Span 3 rows: title, description, button */
    grid-template-rows: subgrid; /* Use the parent's row tracks */
}
```

Now the grid calculates the tallest title across all cards and makes that the height for all title rows — automatically. Descriptions and buttons align perfectly.

## Full Subgrid Example

```html
<div class="grid">
    <article class="card">
        <h2>Short Title</h2>
        <p>A longer description that takes more vertical space than the others. Really fills up the content area.</p>
        <button>Buy Now</button>
    </article>
    <article class="card">
        <h2>A Much Longer Product Title That Wraps</h2>
        <p>Brief description.</p>
        <button>Buy Now</button>
    </article>
    <article class="card">
        <h2>Medium Title</h2>
        <p>Medium length description content here.</p>
        <button>Buy Now</button>
    </article>
</div>
```

```css
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: auto 1fr auto; /* title | content | button */
    align-items: start;
    gap: 2rem 1.5rem;
}

.card {
    display: grid;
    grid-row: span 3;
    grid-template-rows: subgrid;
    background: white;
    border-radius: 8px;
    padding: 1.5rem;
    gap: 0.75rem;
}

/* Each element naturally occupies its track row */
.card h2   { /* Row 1 — tallest title sets height for all */ }
.card p    { align-self: start; } /* Row 2 — content */
.card button { align-self: end; } /* Row 3 — always at bottom */
```

## Column Subgrid

Subgrid works on columns too. Useful for form layouts where labels and inputs in nested structures should align to a parent column grid:

```css
.form-grid {
    display: grid;
    grid-template-columns: max-content 1fr;
    gap: 0.5rem 1rem;
}

.form-section {
    display: grid;
    grid-column: 1 / -1; /* Span full width */
    grid-template-columns: subgrid; /* Inherit column tracks */
}

/* Labels and inputs now align to the parent column grid */
.form-section label { /* Inherits column 1 */ }
.form-section input { /* Inherits column 2 */ }
```

## Nested Subgrid

Subgrid can be nested multiple levels deep. A grandchild can use `subgrid` to inherit the grandparent's tracks, as long as the parent also uses `subgrid` on that axis.
