# JavaScript's New Set Methods: Union, Intersection, and Difference

JavaScript's `Set` has always been useful for deduplication, but set theory operations (union, intersection, difference) required lodash or manual loops. **New native Set methods** — now in all modern browsers and Node.js 22+ — solve this.

## The New Methods at a Glance

All methods are called on a `Set` and accept any **set-like** object (anything with `has`, `keys`, and `size`).

| Method | What it returns |
|--------|----------------|
| `a.union(b)` | All elements in `a` or `b` |
| `a.intersection(b)` | Only elements in both `a` and `b` |
| `a.difference(b)` | Elements in `a` but not in `b` |
| `a.symmetricDifference(b)` | Elements in either but not both |
| `a.isSubsetOf(b)` | Boolean — is every element of `a` in `b`? |
| `a.isSupersetOf(b)` | Boolean — does `a` contain every element of `b`? |
| `a.isDisjointFrom(b)` | Boolean — do `a` and `b` share no elements? |

## Union

```js
const fruits = new Set(["apple", "banana", "cherry"]);
const citrus = new Set(["orange", "lemon", "banana"]);

const all = fruits.union(citrus);
// Set {"apple", "banana", "cherry", "orange", "lemon"}
```

## Intersection

```js
const subscribers = new Set([1, 2, 3, 4, 5]);
const premiumUsers = new Set([3, 4, 5, 6, 7]);

const premiumSubscribers = subscribers.intersection(premiumUsers);
// Set {3, 4, 5}
```

## Difference

```js
const allTasks = new Set(["auth", "api", "ui", "tests"]);
const doneTasks = new Set(["auth", "api"]);

const remaining = allTasks.difference(doneTasks);
// Set {"ui", "tests"}
```

## Symmetric Difference

Returns elements that are in one set or the other, but not both:

```js
const teamA = new Set(["Alice", "Bob", "Carol"]);
const teamB = new Set(["Bob", "Dave", "Eve"]);

const exclusiveMembers = teamA.symmetricDifference(teamB);
// Set {"Alice", "Carol", "Dave", "Eve"}
```

## Subset and Superset Checks

```js
const required = new Set(["read", "write"]);
const userPerms = new Set(["read", "write", "delete"]);

required.isSubsetOf(userPerms);   // true
userPerms.isSupersetOf(required); // true

const admin = new Set(["sudo"]);
required.isDisjointFrom(admin);   // true (no overlap)
```

## Works With Set-Like Objects

The methods accept any object with `has`, `keys`, and `size` — including `Map`:

```js
const map = new Map([["a", 1], ["b", 2]]);
const set = new Set(["a", "c"]);

set.intersection(map); // Set {"a"} — checks map keys
```

## Before and After

```js
// Before — manual union
const union = new Set([...setA, ...setB]);

// After — native
const union = setA.union(setB);

// Before — manual intersection
const intersection = new Set([...setA].filter(x => setB.has(x)));

// After — native
const intersection = setA.intersection(setB);
```

## Browser and Node Support

All 7 methods shipped in:
- **Chrome 122** / **Edge 122** (February 2024)
- **Firefox 127** (June 2024)
- **Safari 17** (September 2023)
- **Node.js 22** (April 2024)

Safe for production without a polyfill for modern targets.
